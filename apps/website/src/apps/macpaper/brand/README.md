# macPaper placeholder brand

Stand-ins drawn by hand so the catalog copy step and the pages have something to
show before macPaper's identity is exported to `apps/macpaper/design/assets`.
Same files and frames as every other app (`app-icon.svg` on a 280 tile,
`symbol-{ink,paper}.svg` on the 128 grid with 24 units clear); the colour is a
provisional teal declared in `../tokens.css`.

When the real masters land: point `brandSource` in `apps/website/src/catalog.ts`
at `apps/macpaper/design/assets` and delete this folder.
