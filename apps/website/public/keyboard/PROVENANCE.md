# Prototype reference assets

The keyboard model and base/RGB texture atlases were extracted from the public static responses in the HAR file supplied by the user on September 13, 2026. They are Raycast reference assets, not original OpenKlack assets. No license for redistribution was supplied. Retained for the requested parity prototype; replace or obtain permission before a public product release.

Source: https://www.raycast.com/keyboard

- keyboard.glb: https://www.raycast.com/_next/static/immutable/media/keyboard.3ro93waeap5n5.glb
- base.jpg: https://www.raycast.com/_next/static/immutable/media/base.2rqquubqlk5zp.jpg
- rgb.jpg: https://www.raycast.com/_next/static/immutable/media/rgb.2b0rcidn_e7r4.jpg
  The previous Raycast audio sprite and its pitch/EQ profiles have been removed. Current audio comes from the MIT-declared Thock/Mechvibes/kbsim packs documented in ../sounds/NOTICE.txt.
